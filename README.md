# Платформа замовлень НФК НТУ

Веб-платформа для розміщення та виконання навчальних замовлень студентами Надвірнянського фахового коледжу НТУ.

Цей проєкт створений для того, щоб студенти могли зручно публікувати навчальні завдання, знаходити виконавців, обмінюватися файлами, спілкуватися щодо деталей замовлення та відстежувати процес виконання в одному місці.

## Оновлення у версії 2

У другій версії було виправлено та покращено декілька важливих моментів:

* усунено проблему з відкриттям сторінки `/orders`;
* прибрано залежність від `cross-env`, щоб запуск на Windows працював простіше;
* видалено `package-lock.json`, який у деяких випадках міг викликати проблеми під час встановлення залежностей;
* покращено адаптивність інтерфейсу, типографіку та загальне вирівнювання елементів;
* додано плавні анімації появи блоків і більш акуратні hover-ефекти;
* прибрано службові згадки про тестовий режим, щоб інтерфейс виглядав чистіше.

## Основні можливості платформи

Платформа підтримує:

* реєстрацію лише через корпоративну пошту коледжу `@nfcntu.ukr.education`;
* розподіл ролей користувачів (замовник, виконавець, адміністратор);
* створення, перегляд, пошук і фільтрацію замовлень;
* сторінку замовлення з детальною інформацією, статусом виконання, журналом активності, файлами та чатом;
* систему відгуків, рейтингу, репутаційних балів і рівнів виконавців;
* портфоліо завершених робіт;
* окремі dashboard-панелі залежно від ролі користувача;
* адміністративну панель зі статистикою, користувачами та замовленнями;
* початкові тестові дані для швидкого запуску після встановлення.

## Використані технології

Проєкт реалізований із використанням таких технологій:

* Node.js 20+
* Express.js
* PostgreSQL 16+
* EJS
* express-session + connect-pg-simple
* pg / pg-mem
* multer (для роботи із вкладеннями)

## Швидкий запуск без окремої бази даних

Для зручності в архів уже додано `node_modules`, тому проєкт можна запустити відразу після розпакування без виконання `npm install`.

### Windows

Запустіть файл:

```text
start-platform.bat
```

### macOS / Linux

```bash
./start-platform.sh
```

### Запуск через npm

```bash
npm run start:memory
```

Після запуску відкрийте у браузері:

```text
http://localhost:3000
```

Тестовий обліковий запис адміністратора:

```text
admin@nfcntu.ukr.education
пароль: College2025!
```

## Запуск із PostgreSQL

### 1. Створення бази даних

Створіть базу:

```sql
CREATE DATABASE nfcntu_platform;
```

### 2. Створення файлу `.env`

Скопіюйте `.env.example` у `.env`.

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

macOS / Linux:

```bash
cp .env.example .env
```

### 3. Налаштування підключення до БД

У файлі `.env` вкажіть параметри підключення.

Приклад:

```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/nfcntu_platform
SESSION_SECRET=your-strong-session-secret
AUTO_SEED=true
```

### 4. Встановлення залежностей (за потреби)

Якщо залежності відсутні:

```bash
npm install
```

### 5. Ініціалізація бази даних

Виконайте:

```bash
npm run db:setup
```

### 6. Запуск сервера

Після цього запустіть застосунок:

```bash
npm start
```

## Додаткові примітки

* вкладення користувачів зберігаються у `storage/uploads/`;
* перевірка корпоративного домену працює як на рівні інтерфейсу, так і на бекенді;
* категорії та групи можна змінювати через довідники або seed-дані;
* для демонстрації під час захисту найзручніше запускати проєкт через `start-platform.bat` або `npm run start:memory`, оскільки це дозволяє швидко підняти систему без окремого налаштування PostgreSQL.
